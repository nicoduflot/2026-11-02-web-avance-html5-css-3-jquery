Ajouter du CSS aux pages html

il faut créer un fichier avec l'extension .css et le lier aux pages qui l'appliqueront à l'aide d'une balise <link>.

<link rel="stylesheet" href="./css/style.css" media="screen">
<link rel="stylesheet" href="./css/print.css" media="print">

Le CSS navigateur

Les navigateurs possèdent leur propre CSS de base (user agent stylesheet ou feuille de style de l'agent utilisateur) qu'ils appliquent par défaut à toutes pages ouverte. Les CSS qu'on ajoute va ajouter ou supplanter des propriétés à ce CSS.

La plupart des navigateur utilisent la même base CSS, avec des concepts hérité des premières pages HTML des années 90, comme beaucoup de site (sinon la plupart) sont construits par rapport à ce CSS, il est impossible de purement le supprimer ou de le réformer dans les navigateurs.

Les marges imposées

Beaucoup de marges extérieures (margin) sont imposées par le navigateur. La plupart ne sont pas gênantes en revanche celles, par exemple, imposées à l'élément <body> peuvent rendre une mise en page impossible.

Les tailles des éléments

Par défaut, quand on impose une taille (hauteur ou largeur) à un élément, le usezr agent utilise le calcul content-box, c'est à dire que la taille est imposée au contenue, sans tenir compte des marges intérieures (padding) et de la largeur des bordures.

Sélecteurs et pseudo-classes

Sélecteurs avancés :is() / :not(), :where(), :has()

  • :is() (Le factoriseur) : Permet de regrouper plusieurs sélecteurs pour éviter les répétitions. Sa spécificité s'adapte à celle du sélecteur le plus fort qu'il contient.

    /* Au lieu d'écrire : header h1, header h2, header h3 */
    header :is(h1, h2, h3) {
        color: #333;
    }

  • :where() (Le factoriseur à spécificité nulle) : Fonctionne exactement comme :is(), mais sa spécificité est toujours de 0. C'est idéal pour créer des styles de base ou des frameworks CSS facilement écrasables.

    :where(article, section) p {
        margin-bottom: 1rem; /* Très facile à surcharger ensuite */
    }

  • :has() (Le "sélecteur parent") : La révolution CSS ! Il permet de cibler un élément parent en fonction de ses enfants ou de son contenu.

    /* Sélectionne le <div class="card"> qui CONTIENT une image */
        div.card:has(img) {
        padding: 0;
    }

Pseudo-classes d'état et pseudo-éléments ::before, ::after, :focus-visible

  • ::before et ::after : Des pseudo-éléments qui permettent d'insérer dynamiquement du contenu généré (icônes, séparateurs, puces décoratives) avant ou après le contenu d'un élément. Obligatoire : l'utilisation de la propriété content.

    button.login::after {
        content: " →";
    }

  • :focus-visible : Améliore l'accessibilité (a11y) et l'esthétique. Il applique un style de focus (contour) uniquement lorsque l'utilisateur navigue au clavier (touche Tab), et l'masque lors d'un clic de souris (évitant le vilain cadre bleu persistant après un clic).
    button:focus-visible {
        outline: 3px solid #ff6b6b;
        outline-offset: 2px;
    }


Déclaration globale :root et portée locale

  • Déclaration globale :root : Le sélecteur :root cible la racine du document (équivalent à mais avec une spécificité plus forte). C'est l'endroit idéal pour stocker les variables globales (palette de couleurs, typographies, espacements) accessibles partout.
  • Portée locale : Une variable peut être déclarée dans n'importe quel sélecteur (ex: un composant spécifique). Elle ne sera alors accessible que dans cet élément et ses enfants.

    :root {
        --main-color: #3498db; /* Globale */
    }

    .card {
        --card-padding: 1.5rem; /* Locale (disponible uniquement dans .card) */
    }
    .card p{
        padding: var(--card-padding);/* applique la variable */
    } header p{
        padding: var(--card-padding);/* n'applique pas la variable */
    }

  • La fonction var()
    Pour utiliser une variable, on utilise la fonction var(). On peut également lui fournir une valeur de secours (fallback) au cas où la variable ne serait pas définie.

    :root {
        --main-color: #3498db; /* Un beau bleu */
    }
    .button {
        background-color: var(--main-color, #000);
        /* Le navigateur trouve --main-color,
        il applique donc : background-color: #3498db; */
    }
